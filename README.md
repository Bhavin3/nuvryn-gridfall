# NUVRYN // GRIDFALL

**A neon arcade survival game built with HTML, CSS and JavaScript.**

Move the core, dodge incoming shards, and survive as the grid gets faster.

[![Play Live](https://img.shields.io/badge/PLAY%20LIVE-GRIDFALL-58F7E8?style=for-the-badge&logo=githubpages&logoColor=07111B)](https://bhavin3.github.io/nuvryn-gridfall/)

</div>

---

## Features

- Neon animated arcade UI
- Keyboard controls: `A / D` or `← / →`
- Mobile touch controls
- Progressive difficulty
- Score + local high score
- Score / level pop animations
- Player glow trail + dodge sparks
- Animated obstacles, particles and pulse effects
- Pause / resume
- Sound toggle
- Responsive design
- No frameworks
- No external assets

## Controls

| Action | Desktop | Mobile |
|---|---|---|
| Move Left | `A` / `←` | Left button |
| Move Right | `D` / `→` | Right button |
| Pause | `Space` | Pause button |
| Start / Restart | `Enter` / button | Start button |

## Tech

`HTML5 Canvas` • `CSS3` • `Vanilla JavaScript` • `LocalStorage`
