# NUVRYN // GRIDFALL

A neon arcade survival game built with **HTML, CSS and JavaScript**.

Move the core, dodge incoming shards, and survive as the grid gets faster.

## Features

- Keyboard controls: `A / D` or `← / →`
- Mobile touch controls
- Progressive difficulty
- Score + local high score
- Pause / resume
- Sound toggle
- Responsive design
- No frameworks
- No external assets

## Run locally

Just open `index.html` in your browser.

## Deploy with GitHub Pages

1. Upload all files to a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/(root)`.
5. Save.

## Controls

| Action | Desktop | Mobile |
|---|---|---|
| Move Left | A / ← | Left button |
| Move Right | D / → | Right button |
| Pause | Space | Pause button |
| Start / Restart | Enter / button | Start button |
